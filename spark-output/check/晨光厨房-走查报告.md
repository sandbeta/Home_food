## 🔴 Blocker（4 项，必须立即处理）

### B1 · AdminOrders「做好了」推进按钮 · sage 实底用会反相的 bone · 夜宵 1.38~1.66:1

- **文件**：`src/pages/AdminOrders.jsx:29`
- **命中**：视觉规范 agent + a11y agent 双独立发现
- **问题**：按钮背景是 sage 渐变（不反相），文字用 `var(--color-bone)`（夜宵反相成 `#F3ECEF` 近白），压在浅绿 sage 上夜宵近乎不可见。同文件的 clay 推进按钮已正确用 `--color-on-dark`，**唯 sage 分支独漏**。这是 §7.9 建立 `persona.on` 令牌时的漏网站点。
- **修复**：`color: 'var(--color-bone)'` → `color: 'var(--color-on-sage)'`；顺手扫全站所有 sage 实底上的文字，规矩落成 "sage 实底必取 on-sage"。

### B2 · OrderDetail 首屏 fetch 无 r.ok · 404 崩溃整站白屏 · 无 ErrorBoundary

- **文件**：`src/pages/OrderDetail.jsx:49`
- **命中**：逻辑状态 agent + 异常边界 agent 双独立发现
- **问题**：`fetch().then(r=>r.json()).then(setOrder)` 无 `r.ok` 校验。订单不存在（旧链接、分享单号失效、admin 删单后刷新）→ mock/server 返回 404 + `{message:'Not found'}`（truthy），`if(!order)` 判空失效 → `order.items.map` 抛 TypeError → **整个路由树卸载 = 整页白屏**。轮询分支有 r.ok 检查，唯首屏分支漏。项目无 ErrorBoundary，任何组件抛错都是全站白屏。
- **修复**：
  - 首屏 fetch 补 `if (!r.ok) throw` → catch 里 `setOrder(null)` + `setError(...)`
  - 渲染处防御 `Array.isArray(order.items) ? ... : 空态`
  - **补一个顶层 `<ErrorBoundary>`**（App.jsx 外层），兜所有此类抛错

### B3 · 双端夜宵种子漂移（id 905 / 907 / 915）· 家庭部署对账失效

- **文件**：`src/lib/mockApi.js` + `src/lib/seedNightExtra.js` ↔ `server/data/seed-dishes.json`
- **命中**：逻辑状态 agent（脚本字段级 diff 确认）
- **问题**：违反 PROJECT-HANDOFF §4 红线（mockApi 与 server 一比一复刻）。三处夜宵种子漂移：
  - `905 扬州炒饭` mock ¥16/主食 ↔ server ¥20/主食
  - `907 螺蛳粉` mock ¥18 ↔ server ¥19
  - `915 皮蛋瘦肉粥` mock ¥10/主食 ↔ server ¥17/汤类
- server/data/seed-dishes.json 里三处的值恰好等于 `seedMenuExtra` 中同名菜 `735/767/713` 的值 → 生成 seed-dishes.json 时被同名灌库数据污染。**手机 A 连家庭服务端 · 手机 B 离线 mock 模式，两人看同一道菜价格/分类不同，AA 分摊金额不同**。
