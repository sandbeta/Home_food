# 懒懒 · 玩态主图 SVG

描自 `../proto/panels/p4.png` 的完整裁片 `(180,275)-(645,650)`，画布 465×375。
原裁片留作对照：`play-source.png`。并排预览：`lamb-play-preview.png`。

## 两份文件

| 文件 | 内容 | 用法 |
|---|---|---|
| `lamb-play-color.svg` | 原奶油场景全彩矢量，含墙面、地面、星星、小配角、杯子、围巾 | 海报底图或奶油场景 |
| `lamb-play-color-pink.svg` | 粉色场景全彩矢量，同一几何，从粉化裁片重描 | 今天页粉色主图的矢量版 |
| `lamb-play-line.svg` | 纯墨线，透明底，只留轮廓与深色细节 | 上色、改色、做线稿贴纸 |

三份都不含气泡文字。气泡位置留空，文案在 HTML 里放，避免把「今天状态很好」这类活文案烤死。
2026-10-23 应用主基调改为粉色后，今天页用的是粉化后的裁片；`lamb-play-color-pink.svg` 是同一份原稿的粉色矢量版，线稿透明，粉底上可直接用。奶油场景和 `lamb-play-preview.png` 留作对照。
彩色版的空气泡底、地面线和墙面接缝都保留了；线稿版没有气泡轮廓，适合直接压 HTML 气泡。

## 夜间

彩色版的颜色是烤死的，适合日间和壁纸式展示。
线稿版在深底上会发闷。要放进夜间界面，把线稿文件里的 `fill="#4A3A26"` 全部替换成 `currentColor`，再由外层 CSS 给 `color: #F2C993`；或者直接替换成 `#F2C993`。

## 怎么生成的

- 先把原稿气泡里的旧字用气泡底色抹掉，保留气泡底与地面。
- 彩色版：双边平滑后走 vtracer 0.6.12 的 color + spline，`filter_speckle=6`、`color_precision=6`、`layer_difference=16`。
- 线稿版：按到线色的距离和亮度提取墨线掩膜，走 vtracer binary + spline，`filter_speckle=3`，再把黑色改成墨棕。
- 两份都加了 `viewBox="0 0 465 375"`，可以直接缩放。

其余五个情绪态可以用同一条管线重描。奶油彩色版 175KB，粉色彩色版 167KB，线稿版 31KB。
粉色版先把气泡旧字抹掉，再把墙面、地面、枕头、木桶、围巾这些暖色按 HSV 换到 340°粉，白羊毛、棕耳、绿杯、蓝水保留，最后走 vtracer。
