# apple-design 语言层 · 落地规则表

生成日期 2026-10-17。技能来源 `emilkowalski/skills@apple-design`（安装量 216,658，本地 MD5 `9fb0754ca4c4fa6525d13d6f4a26ead2`）。
这份表把该技能 17 节的定性要求翻译成本项目能直接执行与验收的数值，供 `lamb-miniapp-apple` 原型与后续 `extracted` 正式版共用。

## 0. 与本机既有动效权威的冲突裁决

既有权威（用户定，来源记忆 `feedback-motion-authority`）：常规动效 ≤300ms、禁动画 boxShadow、bounce ≤0.2。
技能默认给 response 0.4（约 400ms 量级）。裁决如下，全项目一致执行：

| 场景 | response | bounce | 落到临界阻尼后的实测收敛 | 依据 |
| --- | --- | --- | --- | --- |
| UI 状态（按压、指示器、切页淡入） | 0.22 | 0 | 约 203ms（2% 判停） | 压在 300ms 线内 |
| 动量手势落位（抽屉、列表行滑删） | 0.28 | 0.2 | 约 300ms 含一次过冲 | bounce 0.2 是既有上限 |
| 详情面板 detent 切换 | 0.26 | 0.12 | 约 260ms | 手势本身带速度，允许轻微过冲 |

技能给的 0.4 不采用。`bounce` 上限 0.2 与技能建议值恰好一致，直接沿用。
阴影一律不做动画：材质层级靠 `backdrop-filter` 的 blur 半径与背景不透明度表达，这两项在面板入场时同帧变化（技能第 12 节 materialize，不是 fade），而 boxShadow 保持静态值。

## 1. 弹簧参数语义（技能第 4 节）

用 Apple 的两参数而非质量-刚度-阻尼三件组。换算固定在 `motion.js`：

```
ω0 = 2π / response      ζ = 1 − bounce      k = ω0²      c = 2ζω0
加速度 a = k·(target − x) − c·v
```

半隐式欧拉，固定子步 1/120s，单帧最多累计 64ms 防止掉帧后发散。判停 `|x−t|<0.5px 且 |v|<0.5px/s`（位移弹簧）或 `|x−t|<0.001`（比例弹簧）。

## 2. 可打断性（技能第 3 节，最高优先）

四条硬规矩，验收时逐条点：

1. 任何重定向只读**presentation 值**：从 `spring.x` 起算，绝不从上一次的目标值起算。
2. 重定向必须带当前 `spring.v`，靠阻尼自然混接，不做硬切（避免"撞墙"速度突变）。
3. 手势驱动的对象禁用 `transition` 与 `@keyframes`；只在完全静态的入场/退场用 CSS 过渡。
4. 2D 位移拆成 x、y 两条独立弹簧（技能明确要求，单条 2D 距离在 x/y 速度不等时会同步错位）。

## 3. 手势模型（技能第 2、6、9、10 节）

- 起点：`pointerdown` 立即给反馈（加 `.is-pressed`，不依赖 `:active`，避免移动端首触延迟）。
- 捕获：`setPointerCapture`，指针越界不断跟。
- 抓取偏移：记住 `grabOffset`，1:1 跟手，绝不把元素中心吸到指尖。
- 速度：维护最近 5 个 `(时间, 位置)` 采样，释放时取窗口内平均速度，单位 px/s，直接交给弹簧。
- 阈值：位移超过 10px 才认定进入拖拽，此前不锁滚动也不吞点击。
- 落位判定：`project(v, d)` 用技能给的指数衰减式 `x = (v/1000)·d/(1−d)`，面板 `d=0.99`（比滚动更跟手），滑删 `d=0.995`；用**投影点**选最近 detent，不是用释放点就近吸附。
- 方向决策用速度符号，不用位置（技能速查表第 9 条）。
- 越界橡皮筋 `rb(o, dim, 0.55) = o·dim·0.55/(dim + 0.55·|o|)`，用于面板拉到超过最大 detent 之后。

## 4. 材质与深度（技能第 12 节）

| 层 | 背景 | backdrop-filter | 用途 |
| --- | --- | --- | --- |
| 浮动导航条 mat-thin | `rgba(254,242,223,.70)` | `blur(20px) saturate(180%)` | dock、顶部导航 |
| 详情面板 mat-thick | `rgba(254,242,223,.86)` | `blur(34px) saturate(160%)` | 底部面板、模态 |
| 遮罩 scrim | `rgba(74,58,38,.34)` | `blur(2px)` | 只在阻塞式任务出现 |

规则：同一处不叠两层浅色半透明（技能原文，可读性会崩）；面板越大 blur 越强、阴影越深；主操作条与 dock 是并行层，用材质与偏移区分，不加遮罩。分区的实底深色面只保留一个，且走 `--color-*-deep`，不新造底色（晨光厨房令牌两向铁律）。
禁止用 `var()` 拼十六进制透明度，需要带 alpha 的令牌一律写 `rgba()` 字面量。

## 5. 排印（技能第 15 节）

字族改 `system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`，把系统字放第一位。字距按字号分档，不再全站一个值：

| 档 | 字号 | letter-spacing | line-height |
| --- | --- | --- | --- |
| display | 30px | −0.021em | 1.06 |
| title1 | 22px | −0.014em | 1.16 |
| title2 | 17px | −0.006em | 1.24 |
| body | 15px | 0 | 1.5 |
| 说明 | 13px | +0.012em | 1.45 |
| 微标签 | 11px | +0.03em | 1.4 |

数字一律 `font-variant-numeric: tabular-nums`。价格与计数同屏时对齐到同一基线。

## 6. 无障碍三查询（技能第 14 节）

- `prefers-reduced-motion: reduce`：删掉位移与过冲，改为 120ms 纯 opacity 交叉淡入；detent 切换瞬时到位；呼吸、蒸汽等循环动画整体停用。
- `prefers-reduced-transparency: reduce`：mat 层背景不透明度升到 .98、blur 归零、遮罩改实底。
- `prefers-contrast: more`：材质退成近实底并加一条描边。

三者都在 `apple.css` 末尾成块，验收脚本要能在 CSSOM 里查到 `prefers-reduced-motion` 条件文本。

## 7. 触摸区与安全区

延续原型已验证的铁律：触摸下限写 `max(44px, Nu)`，不能只给 `u` 的倍数（`u` 随屏缩，44px 不缩，320px 档会全线跌破）。dock 与主操作条都用 `env(safe-area-inset-bottom)` 抬底，内容容器留 `padding-bottom` 给最后一行留出 dock 高度加一个呼吸位，避免遮挡判定失败。

## 8. 多模态反馈（技能第 13 节）

只在**有后果**的动作上发声/振：加购成功、滑删完成、面板落位。`navigator.vibrate` 存在才调，时长 8ms。因果性要求触发点就是那个事件本身（提交那一下），不能延迟到动画结束。视觉与震动必须同帧。过量反馈会被用户整体忽略，这是技能第 13 节 utility 条的原话。

## 9. 信息架构改动（技能第 16 节 Familiarity 与直接命名）

| 原六页路由 | 新结构 | 理由 |
| --- | --- | --- |
| `#home` | tab「今天」 | 直接命名，不用 vague umbrella |
| `#menu` | tab「菜单」＋搜索＋分区列表 | 列表优先于网格，符合可读性与单手操作 |
| `#dish` | **不再占一个 tab**，改为可拖拽详情面板 | 面板从触发行锚定展开、可中途抓取反向丢弃（技能 3、7 节） |
| `#cart` | tab「锅巴」＋行内左滑删除 | 就近操作替代二级页 |
| `#profile` | tab「我的」 | 外观开关收进这里 |
| `#night` | 降级为**外观态**（data-theme），保留同名路由供验收 | 宵夜不是页面，是同一套内容的第一/深色表现 |

## 10. 原型实测推翻掉的四条（正式版必须照此执行）

1. 背景推远不许用 scale。技能第 12 节的 push back 若实现成 `scale(.955)`，390px 档下 dock 内按钮被缩到 42px，触摸区判定全灭。只保留位移与透明度。
2. 带文字的面一律实底。搜索框、分段控件用 `rgba()` 半透明底时，对比度脚本按元素自身背景算出 1.67:1；换实底令牌后同一处 4.84:1。
3. 拖拽起点记 pointerdown 当时的弹簧值，不是某个固定 detent，否则从中间档起拖会瞬间跳 194px。
4. 验证跨进程往返测不出跳变：两次 `Runtime.evaluate` 间隔约 50ms，高速弹簧已走出 57px。可打断性断言必须在页内同一任务里读前后值。

工具坑两条：验收脚本每次换新 `--user-data-dir`（复用旧 profile 会渲染上一版模块，同一张 PNG 字节数相同即此信号），cache-buster 挂在 `#` 之前；脚本里同时用 `require` 与顶层 `await` 会撞 `ERR_AMBIGUOUS_MODULE_SYNTAX`，改 `.mjs`。
