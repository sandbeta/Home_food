## 2. 做了什么

### 2.1 信息架构

四个主 tab：今天、菜单、锅巴、我的。菜品详情从一级页面改成可下拉关闭的面板，菜单和首页都能直接拉起。旧版的点菜、订单、收藏、冰箱、纪念日、愿望、评分、AA、共享购物车、后台五个页面全部保留。

旧路由 `#/home`、`#/profile`、`#/favorites`、`#/checkout`、`#/dish/:id` 都做了兼容。被裁掉的四页旧书签会回到“我的”。

### 2.2 视觉

- 今天页用手绘小羊。六种情绪态的插画裁自你 10-18 的六屏原型，头像和餐桌小配角也来自同一套图，没有另用 AI 生图。主图把墙面、地面、枕头、木桶和围巾粉化，白羊毛、棕耳、绿杯、蓝水保留。
- 菜单、锅巴、我的、后台走功能轨。白卡加玫瑰投影，容器不描边，正文只有墨色和次墨两档，coral 只出现在大字号句中焦点。主基调浅樱粉，停靠栏玫瑰粉。
- 夜间是外观态。深玫底、奶油字、金色激活面，21:00到05:00自动切，也可以手动钉住。
- 字号、间距、圆角、触控、动效全部收进 `src/styles/tokens.css`。没有 Tailwind，没有散落色值，输入框本身也撑到44px。

### 2.3 工程

- 数据层与旧服务端逐条对齐：`/api/dishes`、`/api/orders`、`/api/anniversaries`、`/api/wishes`、`/api/ratings`、`/api/settlements`、`/api/cart/share`。
- 浏览器 mock 与家庭服务端双轨保留，购物车、收藏、冰箱、身份沿用旧本地键，老数据能接上。
- 菜品候选池重写为 `src/lib/pick.js`：收藏、常点、许愿与纪念日绑定菜、新菜、最近吃过、心情倍率、每日稳定种子。今日主推和“换一道”共用同一个池。
- 弹层用 framer-motion 弹簧；左滑删除带投影落位；减动效在系统偏好和“我的”里都能关。
- 后台沿用公网管理密码门，写法改成新令牌。

## 4. 没做的和要你知道的

- 没有切正式版。家庭服务端默认还指 `extracted/dist`，旧界面仍是家人打开8787看到的那套。
- 没有 Service Worker 和 PWA 安装。
- 日历、口味画像、年度报告、热榜按范围裁掉；年度别册和口味雷达的代码没有搬过来。
- 菜品面板从 `#/dish/:id` 深链打开后，关闭面板地址仍停在该路由，背后是菜单。
- 后台上下架只有眼睛图标和 aria-label，没有可见文字。
- UI 验证是CDP审计加截图，没有组件测试框架；纯函数测试11项。
- 手绘场景来自700px宽的原型分镜，2倍屏会略软；要更清晰需要原始PSD或矢量稿。

## 5. 我的建议

先让家庭服务端指向 `app-next/dist` 跑一天，别急着删旧版。具体做法是备份 `extracted/dist` 后把新构建拷进去，或者把 `server/index.cjs` 的 `DIST_DIR` 改到 `../app-next/dist`。确认家人手机、公网隧道、管理密码门都正常，再把 `extracted/src`、`public`、`dist` 归档到 `archives/20261023-旧版晨光厨房/`，最后把 `app-next` 换成新的主工程。

这会改家人正在用的界面，也会动服务端的静态目录。要我现在切，还是你先在 `localhost:5180` 和 `localhost:4180` 看两天？
