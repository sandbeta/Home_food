## 五、UI 设计稿 / 新视觉语言方向（重点）

### 5.1 新视觉语言代号：**「暗房晚宴 / Midnight Supper」**
- **核心隐喻**：专业美食摄影棚 —— **暖色主光（我）+ 冷色辅光（TA）+ 暗调底片**。暗调让全屏美食图自然成为画面最亮处而「发光」。
- **气质**：电影感、克制、高级、有氛围；从「温暖可爱」转向「夜宴高级」。
- **为什么让食物发光**：暗调暖黑底 + 大图高对比 → 食物即最亮区；金色作为**唯一品牌强调**只在 CTA / 激活态出现，绝不抢食物画面；磨砂玻璃让文字浮于图上仍可读。

### 5.2 新配色（沉浸式、以摄影为主、有氛围）— hex + 理由

| Token | Hex | 角色 | 理由 |
|---|---|---|---|
| `--color-ink-900` | `#0E0C0A` | 页面底色（暖调近黑） | 像暗房/胶片，使食物提亮发光；比纯黑更暖更高级 |
| `--color-ink-850` | `#16130F` | 次级表面/分区 | 暗调层次 |
| `--color-ink-800` | `#1E1A15` | 浮起玻璃卡底座 | 玻璃卡下的暗托 |
| `--color-bone` | `#F5F1EA` | 主文字（骨白/象牙） | 暖白，暗底上清晰且不刺眼 |
| `--color-ash` | `#A89F92` | 次文字（暖灰） | 弱化信息 |
| `--color-mist` | `#6E665C` | 三级/占位 | 更暗暖灰 |
| `--color-gold` | `#E6B25A` | **品牌主强调=「我们」/ 暖主光 / CTA / 激活的我** | 取代 `#FF6B5B`：烛光/高级餐饮，比珊瑚更克制高级 |
| `--color-gold-soft` | `#F0CE92` | 金色高光 | 渐变与高光 |
| `--color-platinum` | `#C2C7D2` | **TA 强调=冷辅光/partner** | 取代 `#6C7FE0`：用冷铂金而非蓝，避开「旧蓝」且更高级 |
| `--color-platinum-soft` | `#DDE0E8` | 铂金高光 | 渐变与高光 |
| `--color-glass` | `rgba(245,241,234,0.06)` | 磨砂玻璃填充 | 极低白透明 + blur |
| `--color-glass-border` | `rgba(245,241,234,0.12)` | 玻璃发丝边 | 1px 暖白描边 |

| `--color-love` | `#E8A6A0` | 浪漫微细节（KissIcon） | 暖陶土粉，取代刺眼 `#FF5A6E` |
| `--color-gold-gradient` | `linear-gradient(135deg,#F0CE92 0%,#E6B25A 100%)` | 主按钮/Orb 渐变 | 烛光金 |

### 5.3 布局系统（贯穿不同页面类型的「一致语法」）

**三段式语法（全站统一）：**
1. **全屏底片层 `FullBleedHero`**：每页底层一张全屏美食图（`object-cover` + 暗角 vignette）。**功能型页面**则「模糊 + 压暗 40–60%」作背景，保证可读。
2. **浮起玻璃层 `GlassCard`**：圆角磨砂玻璃卡从底部**浮起**盛装内容 —— 这是贯穿全站的「内容容器」语法，统一入场动效（y:24→0, opacity, ease-out）。
3. **悬浮玻璃药丸导航 `FloatingPillNav`**：底部居中悬浮磨砂药丸，仅图标 + 激活态；取代旧实底老 TabBar。`D3CartOrb` 保留为悬浮金色 orb。

**两类页面原型：**
| 类型 | 页面 | 布局要点 |
|---|---|---|
| **沉浸型 Hero/Feed** | Home / Menu / DishDetail / Favorites / MyOrders / OrderDetail / Profile | 大图主导 + 玻璃卡浮起 + 滑动；底部悬浮药丸导航 |
| **功能型 Functional** | Cart / Checkout / Admin / AdminDishes / AdminOrders | 压暗全屏背景 + 玻璃「控台」面板（可滚动、密度更高但仍用同一令牌）；底部导航可隐藏或保留药丸 |

**逐页布局草图（要点）：**
- **Home**：全屏签名菜 hero + 顶部 🐱/🐰 头像 + 悬浮药丸导航 + 玻璃 CTA「开始点餐」；`D3CartOrb` 悬浮。
- **Menu**：全屏分类 hero 随选中切换；可滑动菜品卡（`D3FlipCard` 正面图/背面信息）；顶部玻璃分类筛选 chip。
- **DishDetail**：全屏菜品图 + 滑动切角度；玻璃卡从下滑入，含价格 + 「为我加/为TA加」头像切换。
- **Cart**：双栏玻璃卡（我=金发丝边 / TA=铂发丝边），各自小计 + 全局 `split`；底部谁买单入口。
- **Checkout**：玻璃卡覆盖压暗 hero；谁买单三药丸（AA/我请/TA请，选中对应色描边+微辉光）+ 留言框 + 订单摘要。
- **MyOrders**：暗底玻璃列表；行内状态点。
- **OrderDetail**：订单大图 + `D3StatusRing`（金=制作中/铂=待处理/鼠尾草=已完成）玻璃卡。
- **Profile**：大头像 hero 含 🐱/🐰 身份切换；玻璃面板分组设置。
- **Favorites**：沉浸卡片流，角标「我收藏/TA收藏」。
- **Admin\***：暗底 + 玻璃控台面板（高密度表格/表单），令牌一致、可读性优先。

### 5.4 字体 / 间距 / 圆角 / 动效原则

**字体（从圆体可爱 → 编辑/菜单高级）：**
- 标题/Display：衬线 —— 中文 `Noto Serif SC`，拉丁 `Playfair Display`（或 `Cormorant Garamond`）。
- 正文/UI：无衬线 —— 中文 `Noto Sans SC`，拉丁 `Inter`。
- 数字/价格：衬线数字（Playfair）+ `tabular-nums` 对齐，显优雅。

**间距（8pt 栅格）：** 卡内边距 24/28；区块间距 24–32；为悬浮导航预留安全区 `safe-bottom`。

**圆角（大柔角=高级）：** 玻璃卡 28px ／ 药丸 999px ／ 按钮 16px ／ 小控件 12px。

**动效原则（Framer Motion）：**
- 入场：玻璃卡统一「从底部浮起」（y:24→0, opacity, ease-out ≈0.5s）。
- Hero：缓慢 Ken Burns（scale 1.04→1.0）循环，让大图「呼吸」。
- 滑动：菜品卡 spring 拖拽 / 滑动切换；DishDetail 图片滑动。
- 双人格态：当前激活者头像/边框 金/铂 **辉光脉冲**。
- 微交互：卡片 hover 轻微上浮；`KissIcon` 心跳；按钮 tap `scale 0.97`。
- 模态：`AddDishModal` 从下滑入。
- 降级：`prefers-reduced-motion` 全关。

### 5.5 双人格（我/TA）在新语言里的表达
- **不再用「珊瑚 vs 长春花蓝」双主色**，改用 **温度对比 = 暖金(我) vs 冷铂(TA)**，呼应「暖主光/冷辅光」摄影隐喻，比旧色更克制高级。
- **表达手段（不止颜色）：**
  1. **头像 chip**：🐱(我) 金边 + 「我」字标；🐰(TA) 铂边 + 「TA」字标。出现在 Header / 菜品卡 / 购物车 / 结算。
  2. **激活态**：当前点餐者（`whoAmI`）的头像/边框 辉光脉冲（金 for me / 铂 for TA）。
  3. **购物车拆分**：两张玻璃卡（我=金发丝边 / TA=铂发丝边），各自金额与小计（接 `split`）。
  4. **谁买单选择器**：AA / 我请 / TA请 三玻璃药丸，选中态用对应强调色描边 + 微辉光。
  5. **大图卡头像角标**：Menu / DishDetail 卡片叠 🐱/🐰 小角标表示「谁加的」。

## 六、待确认问题 / 假设（需主理人或用户拍板）

1. **图片素材**：是否有成体系高质量美食大图？还是先用占位图（Unsplash 等）？沉浸式大图方向强依赖图源质量。*假设*：先用 6–10 张精选占位，交付前替换为真实素材。
2. **双色编码确认**：本方案用「暖金(我)/冷铂(TA)」温度对比（取代珊瑚/蓝）。是否接受「仍保留两种强调色」？还是要求**完全无双色**、纯靠头像/激活态区分？需拍板。
3. **字体加载**：中文衬线(Noto Serif SC)+无衬线(Noto Sans SC) 体积较大，H5 离线场景是否允许 web font？还是用系统衬线（苹方/微软雅黑）兜底？
4. **D3 技术确认**：已确认为 CSS3D + Framer Motion（非 WebGL），重换肤仅改材质/颜色/光。*请架构师确认*。
