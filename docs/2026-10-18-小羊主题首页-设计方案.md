## 0. 一句话

把小程序的**第一个 tab 换成这张图**：一只占屏 60% 宽的小羊，按真实状态换情绪，四周挂一圈能点的真数据卡，其余 19 条路由一行不动。

这份方案是**给实现读的**：每个组件给了数值，每处与原型不一致的地方都写明了为什么不一致。

## 1. 原型解读：6 屏 ≠ 6 个页面

| 原型屏 | 实际身份 | 还原去向 |
|---|---|---|
| 屏1 躺枕睡觉 + Z 字 | 首页 · 情绪「睡」 | 默认态 |
| 屏3 莲花打坐 + 放射光 + 好运/有钱/美丽 | 首页 · 情绪「祈」 | 下单成功 / 抽到今日主推 |
| 屏4 墨镜喝饮料 + 配角挥手 + 四角星 | 首页 · 情绪「玩」 | 周末 / 本周已开火 ≥3 次 |
| 屏5 木桶泡澡 + 泡泡 + 圆形遮罩构图 | 首页 · 情绪「浴」 | 宵夜窗口（22:00–02:00） |
| 屏6 斜切大圆 + 特写偷吃 + 「你在偷吃吗？」 | **动效帧**，不是页面 | 点角色的特写过场 |
| 屏2 灵动岛 + 周历条 + 手册 + 步数 + 音乐 | **第二屏**（信息密度版） | 首页上滑第二屏 / `#week` |

chrome（顶栏 + 贴纸行 + dock + 挂件行 + 草地条）在屏1/3/4 上是**同一套**——元素、顺序、尺寸一致，只有 hero 换人。这条决定了实现结构：**一个布局壳 + 一个情绪状态机 + 一组挂件**，不是六份界面。

⚠ 但"同一套"是**看**出来的，不是量出来的：把 p1/p3 按纵向 20 条带逐带求差，连顶栏和 dock 都差 20–45（原始数据 `批次B-chrome同一性验证.txt`）—— 六张稿子在拼图时手机摆位没对齐，**面板图不能当描图底稿逐像素还原**，位置只能按 §4 的比例表来。

## 2. 落地形态裁定

采纳 **A：首页即陪伴页**（opencode 推荐 B：新增独立 tab —— 未采纳，理由见 §10 裁定表第 8 条）。

```
今天(首页·装饰轨)  →  菜单  →  锅巴(购物车)  →  我的
     ↑ 本方案范围        ↑ 保持 lamb-miniapp-apple 现状，功能轨，不加放射光/贴纸
```

- 首页走**装饰轨**：允许放射光、地面带、贴纸、泡泡字、歪斜。
- 其余 tab 走**功能轨**：容器零描边零投影、无装饰焦点、信息密度优先。
- 两轨之间**只共用令牌，不共用组件**。这是防止"首页好看、菜单一眼回到外卖 App"的唯一办法。

## 3. 令牌层（实测值，新增 3 支，其余沿用）

单位 `1u = 屏宽 / 100`；Web 端 `--u: min(1vw, 3.9px)`；小程序端 `1u = 7.5rpx`。基准机 390×844。

```css
:root{
  /* —— 沿用已验证的（原型实测与既有令牌同值，不动） —— */
  --page-bg:#FFF2E1;        /* 实测 15–33%/屏，原型主底 */
  --card:#FFFFFF;           /* 实测 #FFFFFE */
  --caramel:#F3CC97;        /* dock / 色块底，实测 #F3CC97~#F4CE9F */
  --ink:#4A3A26;            /* 唯一深色：描边+正文+投影色相。实测最暗0.2%带 #301D10~#4C3524 跨它 */
  --ink-a11y:#7A6349;       /* 需被读出的次级文字 5.12:1 */
  --coral:#DD615C;          /* 实测，比旧 #E06A5A 更准；仅 ≥t2、一屏≤1个词 */
  --blush:#FDC8C6;          /* 腮红，实测 */
  --sky:#DAEFF9;            /* 汗滴 / 泡泡 */
  --sage:#B4C3A4;           /* 图标底 / 草地条 / 星期字浅档 */
  --honey:#FDE0B2;          /* 数字胶囊底 / 选中底 */
  --ear:#96704F;            /* 耳与角：实测 #9A7355~#A7805A，旧 #8A6242 偏暗 */
  --shadow-warm:rgba(160,110,50,.30);   /* 全站唯一投影，禁动画 */

  /* —— 本方案新增（原型里有、体系里没有） —— */
  --floor:#E8C7A1;          /* hero 地面，比 caramel 暗一档（实测 #E8C7A1~#EFC697） */
  --grass-deep:#87956E;     /* 草叶与草地条上沿（实测） */
  --ray-dark:#FFE0B2;       /* 放射光深楔（实测，旧 #F8D488 太重） */
  --ray-light:#FEF4D8;      /* 放射光浅楔 */
  --sage-text:#8FA081;      /* 竖排标签文字用深一档，浅 sage 在白底只有 1.86:1 */
  --apple-off:#C6CBB8;      /* 未点亮苹果：灰绿，不用中性灰（骨架屏禁灰同一条） */
}
```

**明确不进实现的**：原型每屏外面那圈焦糖圆角壳 + 投影，是稿子的手机壳，不是界面。实现最外层只能是屏。

## 4. 首页布局（纵向按占屏高，尺寸按 u）

| 区 | 占屏高 | 内容 |
|---|---|---|
| A 顶栏 | 0–13% | 头像 · 昵称 · 时间 · 陪伴天数 · 色卡 · 日期 |
| B 贴纸行 | 13–19% | 礼盒 · 便签（左）｜苹果进度 5 颗（右） |
| C hero | 19–46% | 墙面/地面分界 ·（祈态）放射光 · 角色 · 竖排星期五 · 外挂符号 · 气泡 |
| D dock | 46–57% | 4 格：吃饭 / 睡觉 / 玩耍 / 洗澡 |
| E 挂件行 | 57–82% | 左：2 个图标格｜中：玻璃罩今日剩余｜右：生日倒计时卡 |
| F 草地条 | 82–100% | 躺羊（破上沿 2u）+ 左右两个圆角方按钮 |

安全边 5u；组间 ≥7u、组内 ≤3.5u；**留白是唯一分组手段**，不加分隔线。

### 组件规格

**A-1 头像** 8u 圆，`--card` 底，`--sage` 描边 0.6u，内嵌羊探头（复用 `art.js` 的 `lamb('head')`，只画羊毛 + 两耳 + 半睁眼）。

**A-2 昵称** 泡泡字，高 5.5u，`--honey` 填充 + `--ink` 0.6u 描边，右跟一支 3u 铅笔。**泡泡字全站只允许出现在这一处和角色说的话上**（沿用规范：泡泡字是角色名专用）。

**A-3 时间** 8u / 700 / `--ink` / `tabular-nums`，圆头数字体。

**A-4 陪伴天数** 3.4u / `--ink` / `letter-spacing:.18em`，格式 `陪伴懒懒 {pad3(n)} 天啦`。

**A-5 色卡** 5 格 1.2u 见方、间距 0.6u，取低饱和彩虹 `#D4B0A4 #E9C69F #F3E2A4 #D9E4A5 #BEC3DC`，当前星期高亮那一格换成 `--coral`，其余 60% 透明。**这是纯装饰，不承载数据**，所以允许它没有语义 —— 但要在代码注释里写明，免得下一个人去给它接数据。

**B-1 贴纸** 礼盒 6u、便签 5u，`transform: rotate(-4deg)` / `rotate(6deg)`，白 die-cut 边 0.8u（**贴纸是全站唯一允许白边的东西**，规范禁的是容器白边）。

**B-2 苹果进度** 5 颗 × 2.6u，间距 1u。已达成 `--coral` + `--ink` 0.6u 描边 + 一片 `--sage` 叶子；未达成 `--apple-off` 无描边。点击 +1（本地存储），到 5 弹一次气泡。

**C-1 墙面/地面** 上 `--page-bg`、下 `--floor`，分界线在 hero 高 55% 处、右侧带一条 12° 斜线（原型屏1 右下角那道）。分界线 0.4u `--ink` 12% 透明。

**C-2 放射光**（仅祈态）**双层**：里层 16 个硬边扇形，`i%2` 交替 `--ray-light` / 次浅一档（介于 `--ray-light` 与 `--honey` 之间，取 `#FFF0CE`），圆心在角色胸口，半径 42u；外层一圈 **12–16 枚 `--ray-dark` 圆头胶囊**（6u 长 × 2u 宽，径向排布，距圆心 30–40u）。**禁止 conic-gradient**（会糊出渐变边），两层都用 `<path>` 画。

**C-3 竖排标签** 左 3u，白底 radius 4u，宽 7.5u，三字竖排 4u / 行高 1.15 / `--sage-text`，末字「五」用 `--coral`。内容 = 由日期算出的星期，不写死。

**C-4 气泡**（角色台词）白底 radius 5u，`--ink` 0.8u 描边，尾巴同色三角 1.5u，字 3.4u `--ink`，**泡泡字例外**：原型里「你在偷吃吗？」「没事哒」是描边加粗的泡泡字，裁定保留 —— 判据是"这句话是角色说出口的"，功能文字一律不许。

**D dock** `--caramel` 底，radius 5.5u，**border:none / box-shadow:none**，4 格等分、图标 9u、标签 3.4u `--ink` `.18em`，格间空隙 ≥5u。按下 `scale(.96)`，不加描边不加高亮底。图标：吃饭 = 草莓蛋糕、睡觉 = 枕头、玩耍 = 小黄鸭、洗澡 = 洗手液（沿用原型，别换成抽象线性图标）。

**E-1 图标格** 12u 见方 radius 4u，底 `--sage` / `--honey` 交替，内画**配角小不点**（光滑蛋形 + 两根触角，无花边无角，每屏 0–2 次）而不是品牌 logo。标签 3.4u。

**E-2 玻璃罩「今日剩余」** 全图最好的一个原创件，照抄：18u 宽 × 26u 高，罩盖是配角头（10u 圆 + 两根触角），罩身 `--card` 30% + `--ink` 0.6u 描边，里面一支玫瑰：花冠 `--blush`、茎叶 `--sage`、底座 `--floor`。`--honey` 胶囊上写百分比 4u / `tabular-nums`。**玫瑰开放度 = 剩余比例**：100% 全开、50% 半开、<20% 低头掉瓣（3 档 SVG，不做连续变形）。

**E-3 生日倒计时卡** 40u × 24u，`--card` 底 radius 4u 无描边，文案 `距离 生日 还有` + `--honey` 胶囊内 365 + `天`，其中「生日」二字 `--coral`（**一屏唯一 coral 词**），羊 + 蛋糕插画压在卡右下角、**破卡边 ≥1u**。

**F-1 草地条** `--sage` 底 + `--grass-deep` 草叶 8–12 根，躺羊 60u 宽压在条上沿 2u；左右两个 12u 圆角方按钮 `--card` 底 radius 4u，图标是道具不是功能符号（左 = 草编包，右 = 棒棒糖信封）。

### 4.1 第二屏（原型屏2 的去处）

首页上滑（或点顶栏色卡）进第二屏，走**半装饰轨**：保留白卡与角色，**不放放射光、不放地面/墙面分界、不放歪贴纸**。原因是屏2 自己数就有 8 张卡，再加装饰就变成"贴纸风外卖大促页"——`style_lint` 的「对比色相面积 ≤6%」和「装饰焦点每屏 ≤1 处」两条会同时红。

| 组件 | 规格 | 数据 |
|---|---|---|
| 周历条 | 白卡 radius 4u，通栏宽 90u、高 34u；内 7 格（**只做周一到周五**，原型只有 4 只是因为它只画到周四）；每格 = 一只 12u 小羊 + 下方 3.4u 星期 + 3u 日期；今天那格下面一条 2u `--coral` 短线 | 7 只羊的姿势 = 该日是否有订单：无单=睡、有单=祈、宵夜单=浴、未来日=灰 `--apple-off` 不画姿势 |
| 「Happy Everyday」 | 3.4u `--ink` `.18em`，居中，压在周历条下 2u | 静态 |
| 今天吃什么卡 | 44u × 44u 白卡 radius 4u，右上 3.4u 问句「今天吃什么喃？」，卡内一只 28u 吃零食的羊 | 点 = 抽今日主推（接 `PotReveal` 的"换一道"） |
| 懒懒手册 | 44u × 40u 白卡，书签图标 4u，标题「-懒懒手册-」3.4u，4 行 3.4u，序号 1–4 用四色（`--sage` / `--honey` / `--coral` / `--sky`）**但序号与正文同色时对比度只有 3:1 以下，正文一律 `--ink`** | 用户自填，v1 本地 4 条 |
| 本周开火卡 | 30u × 40u 白卡，数字 7u `tabular-nums` `--ink`，标签 3.4u | `orders` 本周计数（**取代原型的步数卡**） |
| 音乐卡 | 原型那张网易云卡**整块删**：小程序里播不了别人的歌，且它承载的是"手机桌面感"，在 App 内没有语义 | — |

删掉第三方图标格之后，屏2 剩下 5 个组件，正好落在"每屏 ≤6 张卡"的上限内（这条是 opencode 提的，已采纳）。

## 5. 角色系统

复用 `lamb-miniapp-apple/art.js` 的 `scallop()` / `lamb()` / `mate()`，**但颜色一律走 `currentColor` + CSS 变量，不许内联 hex**（那是给 Figma 的导出件才内联 fill）。

### 5.0 三条实测修正（放大 `design/proto/zoom-wool-p3.png`、`zoom-head-p1.png`、`zoom-head-p4.png` 之后发现的，与上游规范不一致，**以原型为准**）

放大看角色，有三件事跟我一开始按 `style-spec-lamb-13` 写的规格不一样，而且不一样的是最要命的部分：

1. **羊毛不是一圈均匀 14 瓣扇贝。** 原型是 **7–9 个大小不一的大瓣**（左右各 2 大瓣 + 底部 1–2 瓣 + 顶部一个 2–3 瓣的小尖顶，像软冰淇淋那样往上收），**外面还套一圈"内扇贝"**：贴着脸的那道羊毛内缘是 4–6 个软锯齿。所以正确的结构是**两级扇贝**（外缘大瓣 + 内缘小锯齿），不是均匀一圈。照 `art.js` 现在的 `scallop(N=14)` 直接画，会得到一圈饼干压边，人一眼就能看出不是同一只羊。
2. **附件是 4 个，不是 2 个。** 原型每只羊都有 **两枚棕色角**（10 点 / 2 点方向，`--ear`，**角内还有一条更深的中线**，是叶子脉不是涂满）+ **两枚浅色耳垂**（8 点 / 4 点方向，`--card` 底 `--ink` 描边，比角小一档）。上游规范写的"恰好两个 `#8A6242` 小圆叶耳/角"只覆盖了上面那对。跨姿态仍然是硬要求：**角永远在、耳垂在侧躺时会被压掉一侧**（屏1 左侧耳垂就被汗滴挡住了一半）。
3. **放射光是双层，不是单层扇形。** 里层是宽扇形底（`--ray-light` / 次浅一档交替，我原先记成 `--ray-dark` 是错的），**外层还有一圈 12–16 枚 `--ray-dark` 胶囊点缀**（圆头、径向排布、约 6u 长 × 2u 宽）。少了这圈胶囊，祈态会显得"空"。

三条都已经写进批次 B 工单的更正版；`style-spec-lamb-13` 里与之冲突的那两句（"12–16 瓣扇贝""恰好两个耳/角"）**要不要跟着改**，见 §12 第 7 条 —— 因为那套规范还管着 `public/lazy-assets/` 里已有的官方素材，改了规范就得重画存量素材，不该由我单方面定。

### 5.1 其余角色定律（这些实测与规范一致，照旧）

- 2 头身，头（羊毛团）占高 **55–60%**；五官 < 脸 15%、落在脸下 2/3。
- 纯白平涂、无体积无毛流，内侧 2–3 条短弧线。
- 眼 = **一条半睁横线或一条下弯弧**，两枚可以不对称（睡态是两条斜短线）；**不画眉毛**。
- 腮红 = 2 团无描边柔焦椭圆 + 1 个白高光点，**腮红外侧还有 2–3 个 `--blush` 小圆点**（原型放大可见，加上更像）。
- 四肢 = 无指节圆头短棒。
- 一级线宽 1.1u（主体轮廓），二级 0.6u（道具、图标内），round cap/join，单色，**无粗细渐变**。
- 表情靠**外挂符号**表达（Z 字、汗滴、四角星、闪光、泡泡、斜切气泡尾巴），不重画五官。

**6 个情绪状态**（v1 先做前 4 个，后 2 个 v1.1）：

| 状态 | 姿势 | 外挂符号 | 触发（真实数据） |
|---|---|---|---|
| 睡 | 躺枕、盖毯、露脚 | Z 字 ×3（12/9/6u 斜 15°）+ 蓝汗滴 | 当日 00:00–10:00，或今日尚无订单 |
| 祈 | 莲花垫打坐、双手合十 | 放射光 + 好运/有钱/美丽 | 今日已下单，或刚抽到今日主推 |
| 浴 | 木桶、毛巾、闭眼张嘴 | 泡泡 ×5 + 「哈~ 好舒呀~」 | 宵夜窗口 22:00–02:00 |
| 玩 | 墨镜 + 饮料 + 配角挥手 | 四角星 ×3 + 「懒懒玩的很开心~」 | 周六/周日，或本周开火 ≥3 次 |
| 忙 | 抱电脑（屏5 顶圆窗） | 竖排「没事哒」 | 加载 / 空态 / 等待 |
| 偷吃 | 拿勺特写 | 斜切大圆 + 「你在偷吃吗？」 | 宵夜窗口内**又**下了一单 |

**零件预算**：角色动作 6 + 头像 1 + 外挂符号 6 + dock 图标 4 + 配角动作 4 ≈ 21 个零件，比规范的 40–46 上限宽松，够画。

## 6. 数据契约（硬约束）

首页上**每一个数字都必须能指回一条 state 或系统时间**；指不回的删掉。原型里的 `08:08 / 001 / 365 / 50% / 09421 / 2-5` 全是占位。

| 元素 | 来源 | 状态 |
|---|---|---|
| 时间 / 日期 / 星期 / 周历条 4 天 | 系统时间 | ✅ 可实现 |
| 周历条 4 只羊的姿势 | 本周各日是否有订单 | ✅ 可实现（`orders` 有日期） |
| 情绪状态机 | 时间 + 订单状态 | ✅ 可实现 |

## 7. 动效（沿用已定权威值）

- 全部 ≤300ms；只允许**位移 + 缩放 + 透明度**；**禁止动画 `box-shadow`**；bounce ≤0.2。
- 待机：角色呼吸 = `scaleY(1 → 1.015 → 1)`，2.8s 循环，`prefers-reduced-motion` 下停。
- Z 字：三枚依次淡入上移 2u，各 240ms，间隔 400ms。
- 点角色 → 屏6 的斜切大圆从角色位置放大到 55% 屏宽（280ms，ease-out），停 900ms 后收回。**放大层不得压住任何文字**（原型屏4 的焦糖圆压住了 `支付宝`/`50%`，这是原型的瑕疵，照抄就错了）。
- 换情绪：旧角色 240ms 下沉 3u 淡出，新角色 240ms 上浮淡入，**不做交叉淡叠**。
- 转场用飘落/破框，不用淡入淡出。

## 14. 追加（所有者改口径为"像素级还原"之后的结论）

所有者看到 §13 那轮的并排图之后把标准改成**像素级还原、做完为止**。这条改了实现路线，记在这里。

### 14.1 度量先立起来

还原画布从真机 390×844 改成**原型自己的屏幕盒子 326×667**（= p1 面板里量出的 652×1334 的一半），这样 `shot_el.js` 以 2 倍截图正好输出 652×1334，与原型逐像素对齐。配三个工具（都在 `research/20261018-两代理协作/`）：

- `fidelity.py` —— 六个区各自的平均差与"差异>40 占比"，外加一张"原型 / 差异热力 / 50% 叠影"三联图；
- `align_probe.py` —— 在 20 个元素窗口里分别量原型与还原的墨迹盒子，直接报"该往哪移几个百分点"；
- `grid_overlay.py` / `measure_boxes.py` —— 出 2% 网格读数图、量元素 bbox。

对照模式 `?proto=1`：时间/日期/星期钉成原型那组值（08:08 / 10-26 / 星期五）。**这个开关是必需的** —— 否则 harness 一直在把"14:13"和"08:08"当差异算。

### 14.2 两条路线的实测，以及为什么最后两条都留着

| 插画层来源 | 整屏差异>40 占比 | hero 区 | 能跟深色轨换色 | 能画原型里没有的姿势 |
|---|---|---|---|---|
| 参数化重画（opencode 的 `art.js`，5 轮迭代后） | 33.76% | 21.85% | ✅ currentColor | ✅ |
| 锁色板描图（`trace_regions.py` 从原型直接描） | **18.77%** | **10.20%** | ✅ **path 填 `var(--token)`** | ❌ |

描图这一路我把"颜色烤死"这个致命缺陷解掉了：`findContours` 出几何，但 `fill` 一律写 `var(--ink)` / `var(--sage)` 这类令牌而不是十六进制，所以**几何是描的、颜色仍然跟主题**。剩下的唯一硬限制是"画不出原型里没有的新姿势"。

而原型本身已经含 6 个姿势（睡/祈/玩/浴/忙/偷吃），所以对本轮"还原这六屏"的目标来说，描图没有实际损失；参数化那套继续留着，将来加新姿势、做分部动画时用得上。页面开关 `?art=param`（默认）/ `?art=trace`。

描图踩到的两个坑（都会静默骗过度量，已写进坐标表 §11）：色板必须**含背景三层**（否则整片墙被吸成白，heroSleep 假报 67.94%）；cv2 习惯 BGR 而 PIL 出的是 RGB，**距离算之前不翻通道会让每个颜色都配错**（整屏从 18.6 假涨到 43）。

### 14.3 六屏的完成度与"为什么屏4 的分低"

屏1 已收敛到整屏 18.77%（贴纸行 6.98% / 底部 7.36% / hero 10.20% 都进或接近达标线；顶栏 14.22% 的残差主要是**字体** —— 原型是圆头手写体，我们回落到 PingFang，文字层不能描、描了就不是活数据）。

屏3/屏4 的 hero 描图各自只有 2.0–2.7% 的区内差，但**整屏分反而高**（屏4 34.55%）。原因是量出来的：四张面板的屏幕盒子宽高比从 0.489 到 0.527 各不相同，手机在拼图里摆位也没对齐（`批次B-chrome同一性验证.txt`：p1 与 p3 连顶栏和 dock 都差 20–45）。**所以一套 CSS 只能对着一张稿子校准**，拿屏1 的版式去比屏4，chrome 的每个块都算成偏移。这不是还原退步，是参照系不同 —— 要么后面按屏各出一套百分比，要么定一屏为唯一基准（我定的是屏1）。
